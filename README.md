# Google Flow 影片製作與 Codex agent 協作指南

這個獨立 repository 收錄 Google Flow 影片製作手冊，供不同電腦上的 Codex 或其他 agent 參考，涵蓋 Flow MCP 安裝與連線、故事討論、劇本分境、逐鏡提示詞、付費生成授權、素材管理、生成後 QA 與交接。

## 完整手冊

- [Google Flow 影片製作與 Codex 操作手冊](GOOGLE_FLOW_AGENT_GUIDE.md)

## 使用前請留意

- Flow MCP 是第三方社群工具，不是 Google 官方 Flow API。
- Flow 介面、模型、點數、報價和 MCP 上游版本會變動；每次操作都要查當下狀態。
- 手冊中的 SOIL 專案路徑和鏡號是實作案例；其他專案請替換成當前工作區的文件與素材。
- 不要把 Google 登入資料、瀏覽器 profile、cookie、驗證碼或帳戶專屬 Flow 專案 ID 提交到公開 repository。
- 每次付費生成都要依使用者當次明確授權核對模型、提示詞、素材、變體數和點數上限。
